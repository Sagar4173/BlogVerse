## Frequently Asked Questions

### General Questions

**Q: Is BlogVerse free to use?**
A: Yes, BlogVerse is completely free and open-source. We may introduce premium features in the future, but the core platform will always remain free.

**Q: Can I host BlogVerse on my own servers?**
A: Absolutely! BlogVerse is designed to be self-hosted. Check our [deployment guide](deployment.md) for instructions.

**Q: What databases are supported?**
A: Currently, we support MongoDB. We're planning to add support for PostgreSQL and MySQL in future releases.

**Q: Is there a mobile app?**
A: We have a responsive web application that works great on mobile. Native iOS and Android apps are planned for Q3 2024.

### Technical Questions

**Q: What are the minimum system requirements?**
A:

- Node.js 16.0 or higher
- 4GB RAM minimum (8GB recommended)
- 10GB free disk space
- MongoDB 4.4 or higher

**Q: Can I customize the UI/themes?**
A: Yes, BlogVerse supports custom themes and CSS customization. We're working on a theme marketplace for easier customization.

**Q: Does BlogVerse support multiple languages?**
A: Currently, the interface is in English. Multi-language support is planned for Q2 2024, starting with Spanish, French, and German.

**Q: How do I backup my data?**
A: You can export your data through the dashboard. For self-hosted instances, we recommend regular MongoDB backups.

### Development Questions

**Q: How can I contribute to BlogVerse?**
A: Check our [Contributing Guidelines](contributing.md) for detailed information on how to contribute code, documentation, or report issues.

**Q: Can I build plugins/extensions?**
A: Plugin architecture is in development. We'll have a plugin API and marketplace in late 2024.

**Q: Is there an API for mobile app development?**
A: Yes, we have a comprehensive REST API. Check our [API Reference](api-reference.md) for complete documentation.

### Security & Privacy

**Q: How secure is my data?**
A: We take security seriously. All data is encrypted in transit and at rest. Regular security audits are performed. See our [Security Guide](security.md) for details.

**Q: Do you sell user data?**
A: No, we never sell user data. We're committed to privacy and operate under strict data protection principles.

**Q: Can I delete my account and data?**
A: Yes, you can permanently delete your account and all associated data through the account settings.
